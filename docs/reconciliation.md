# Сверка: PostgreSQL и ручная выгрузка

Сверка данных ETL с ручной выгрузкой из TG Booster.

## Период (пример)

| Поле | Значение |
|------|----------|
| Дата начала | 2026-07-07 |
| Дата окончания | 2026-07-13 |
| Источник (ручной) | Excel/CSV, уровень объявлений |
| Источник (БД) | `raw_campaign_stats` |

## Как повторить

```bash
# Итоги в БД за период
python -m etl reconcile --from 2026-07-07 --to 2026-07-13

# Сравнение с Excel-выгрузкой
python scripts/compare_manual_export.py path/to/export.xlsx <account_id>
```

## SQL

```sql
SELECT
    stat_date,
    SUM(spend) AS spend,
    SUM(leads) AS leads
FROM raw_campaign_stats
WHERE account_id = '<cabinet_id>'
  AND stat_date BETWEEN '2026-07-07' AND '2026-07-13'
GROUP BY stat_date
ORDER BY stat_date;
```
